# Simple Go Port Scanner

A basic TCP port scanner written in Go. This project is a simple implementation designed for learning and understanding fundamental network programming concepts in Go. It scans a specified host for open ports within a defined range using goroutines for concurrent scanning.

Features:

* Scans a target host for open TCP ports.
* Uses goroutines for concurrent scanning to improve performance.
* Configurable port range (currently 1-1000).
* Simple command-line interface.
  
#Note: This project is part of a learning journey into Go programming and network scanning. It is a basic example and may not include advanced features or extensive error handling found in more mature port scanning tools. I plan to update this project in the future to include more advanced features as my understanding grows.
